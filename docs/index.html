Built for Speed, Privacy, and Control

Everything you love about modern block-based terminals, freed from commercial servers.

🛡️

100% Private & Offline

No accounts, no sign-ins, and zero analytics packets. OwnTerm works entirely offline without reaching out to any cloud telemetry service.

🧠

Bring Your Own Model (BYOM)

Connect directly to Ollama, vLLM, LM Studio, OpenAI, xAI, OpenRouter, or Groq. Set OWNTERM_PROVIDER and OWNTERM_MODEL. No Warp account.

⚡

Native Tool Calling

The built-in assistant executes shell commands and reads workspace files directly in your terminal buffer with full user confirmation.

🚀

GPU-Accelerated Rendering

Hardware acceleration with Metal and OpenGL ensures instant startup, low latency keystrokes, and buttery-smooth 120 FPS scrolling.

🔑

OS Keyring Security

Your API keys are stored securely in your operating system's native keychain (macOS Keychain, Secret Service, Credential Manager).

🖥️

GUI & Headless TUI

Use the beautiful graphical desktop app on your workstation, or deploy the lightweight ownterm-tui binary on remote SSH servers.

Get Started in Seconds

Point OwnTerm to any OpenAI-compatible engine on your machine or cloud.

# 1. Pull and start your local Ollama model
ollama run llama3.3

# 2. Launch OwnTerm with direct local loopback inference
export OWNTERM_PROVIDER="ollama"
export OWNTERM_MODEL="llama3.3"

./script/run
# 1. Serve high-throughput model with vLLM
vllm serve Qwen/Qwen2.5-Coder-7B-Instruct --port 8000

# 2. Point OwnTerm to the vLLM server
export OWNTERM_BASE_URL="http://localhost:8000/v1"
export OWNTERM_MODEL="Qwen/Qwen2.5-Coder-7B-Instruct"

./script/run
# 1. Start Local Server in LM Studio (default: port 1234)
# 2. Run OwnTerm with your selected LM Studio model
export OWNTERM_BASE_URL="http://localhost:1234/v1"
export OWNTERM_MODEL="qwen2.5-coder-7b-instruct"

./script/run
# xAI, OpenAI, OpenRouter, or Groq. The key stays in the environment.
export OWNTERM_PROVIDER="xai"
export OWNTERM_MODEL="grok-3"
export OWNTERM_API_KEY="xai-..."

./script/run
# Run headless console TUI for SSH sessions, tmux, or containers
./script/run-tui

# Or run compiled standalone binary directly
ownterm-tui
